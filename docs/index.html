Migrate any CI pipeline to GitHub Actions — with AI.

A .NET 10 console app that converts GitLab CI, Azure DevOps, and Jenkins pipelines into production-ready GitHub Actions workflows using the GitHub Copilot SDK. Three AI phases per pipeline — analysis, conversion, validation — running in parallel sessions.

Why you'll like it

Not just a YAML transformer — a three-phase AI workflow that reasons about your pipeline, flags risks, converts intelligently, and validates the result.

🔬

Pre-conversion analysis

Copilot rates complexity (Low/Medium/High/Critical), identifies risks, and flags unsupported features. Critical issues can block conversion.

🤖

AI-powered conversion

Analysis findings are injected into the converter prompt so the model adds TODOs, handles edge cases, and produces idiomatic Actions YAML.

✅

Validation & auto-fix

YAML syntax, Actions structure, security best practices, and action version pinning are checked — improvements applied directly to the output.

⚡

Parallel sessions

Process dozens of pipelines concurrently with independent Copilot sessions throttled by a configurable semaphore.

📊

Live Blazor dashboard

Pass --port to launch a real-time progress UI: per-pipeline phase indicators, elapsed time, and error details.

📝

Customizable prompts

Each phase is driven by a plain markdown prompt file. Tweak instructions for your stack without touching code.

🧩

Extensible

Add new sources by implementing IPipelineSource. CircleCI, Bitbucket, TeamCity — bring your own.

📑

Audit-ready reports

Every workflow ships with .analysis.md and .validation.md reports for review and sign-off.

How it works

Analysis, conversion, and validation all run in the same Copilot session — preserving context for higher-quality output.

  1. 1
    Scan

    Discover pipeline files by matching against registered IPipelineSource patterns.

  2. 2
    Analyze

    Copilot rates complexity, surfaces risks, and flags unsupported features.

  3. 3
    Convert

    In the same session, the converter produces idiomatic Actions YAML informed by the analysis.

  4. 4
    Validate

    Syntax, security, and action pinning are checked. Improvements are auto-applied.

  5. 5
    Report

    Save the workflow plus analysis & validation reports — watch progress live in the dashboard.

Before · After

Real input, real Copilot output — pinned action versions, caching, and job dependencies included.

# .gitlab-ci.yml
stages:
  - build
  - test

build:
  stage: build
  image: node:20
  script:
    - npm ci
    - npm run build
  artifacts:
    paths:
      - dist/

test:
  stage: test
  script:
    - npm test
→
# .github/workflows/ci.yml
name: CI/CD Pipeline

on:
  push:
    branches: [main, develop]

jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version: '20'
          cache: 'npm'
      - run: npm ci
      - run: npm run build
      - uses: actions/upload-artifact@v4
        with:
          name: dist
          path: dist/

  test:
    needs: build
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - run: npm test

Quickstart

Clone, build, run. The included samples cover all three sources out of the box.

Prerequisites

  • .NET 10 SDK
  • GitHub Copilot CLI on PATH
  • Active GitHub Copilot subscription
  • Pipelines you want to migrate 🚀

Run it

git clone https://github.com/Frank802/ghcp-action-importer.git
cd ghcp-action-importer/src
dotnet build

# convert the bundled samples
dotnet run -- -i ../samples -o ../output -v

# or launch the live dashboard
dotnet run -- -i ../samples -o ../output -p 5050

CLI reference

Powerful flags, sensible defaults.

OptionAliasDescription
--input-iRequired. Input directory containing pipeline files
--output-oRequired. Output directory for converted workflows
--source-sFilter: GitLab, AzureDevOps, Jenkins
--max-sessions-mMax parallel Copilot sessions (default: 3)
--port-pStart the Blazor dashboard on the given port
--skip-validationSkip validation step
--skip-analysisSkip pre-conversion analysis
--verbose-vEnable verbose output
